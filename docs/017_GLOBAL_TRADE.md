# 017 — Global Trade

## Scope

Cross-border trading processes spanning procurement through customs.

## Capabilities

| Capability | Description |
|---|---|
| International Trading | Multi-party B2B commerce |
| Import / Export | End-to-end shipment workflows |
| OEM / ODM | Private label manufacturing programs |
| Global Procurement | Centralized sourcing |
| US Purchasing Service | US buy + consolidate + export |
| Customs Documentation | Commercial docs + HS support |

## Trade lifecycle

```
Discover → RFQ → Quote → Negotiate → Order
  → Produce/Pick → Ship → Customs → Deliver → Settle
```

## Commercial terms (planned fields)

- Incoterms (FOB, CIF, DDP, etc.)
- Currency + FX snapshot
- Payment terms
- Inspection / sample gates (OEM)

## Compliance checkpoints

- Restricted party screening (Phase 2)
- HS classification review
- Certificate of Origin eligibility
- Labeling requirements by destination market
