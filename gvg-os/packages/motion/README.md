# @gvg/motion

Cinematic motion system for GVG OS.

| Module | API |
|---|---|
| Scroll Director | `ScrollDirector` / `createScrollDirector` |
| Scene Manager | `SceneManager` / `createSceneManager` |
| Camera Controller | `CameraController` / `createCameraController` |
| Timeline | `createTimeline` / `sequence` / `staggerIn` |
| Parallax | `parallax` / `parallaxLayers` |
| Text Reveal | `textReveal` / `prepareText` |
| Transition | `transitionIn` / `transitionOut` / `crossfade` |
| Particle Engine | `ParticleEngine` / `createParticleEngine` |

```ts
import {
  createScrollDirector,
  textReveal,
  createParticleEngine,
} from "@gvg/motion";
```
