# @gvg/ui

Shared UI for GVG OS apps.

| Component | Import |
|---|---|
| Button | `@gvg/ui` / `@gvg/ui/Button` |
| Card | `@gvg/ui/Card` |
| Modal | `@gvg/ui/Modal` |
| Table | `@gvg/ui/Table` |
| Grid | `@gvg/ui/Grid` |
| Form | `@gvg/ui/Form` |
| Charts | `@gvg/ui/Charts` |
| Timeline | `@gvg/ui/Timeline` |
| CommandPalette | `@gvg/ui/CommandPalette` |
| DataGrid | `@gvg/ui/DataGrid` |
| TreeView | `@gvg/ui/TreeView` |
| Dock | `@gvg/ui/Dock` |
| GlassPanel | `@gvg/ui/GlassPanel` |

```ts
import { Button, Card, DataGrid, Dock } from "@gvg/ui";
```

Uses `--gv-*` CSS variables from the design system / theme.
