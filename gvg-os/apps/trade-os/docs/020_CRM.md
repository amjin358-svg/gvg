# 020 — CRM

## Module

Route: `/crm`  
Primary roles: Sales, Purchasing, Admin, Super Admin

## Objects

| Object | Description |
|---|---|
| Account | Buyer or supplier organization |
| Contact | People at account |
| Opportunity | Pipeline around RFQ/OEM program |
| Activity | Calls, emails, notes, tasks |
| Owner | Internal role owner (sales/purchasing) |

## Account types

- Customer
- Business Customer
- Supplier
- Logistics Partner (future)

## Workflows

1. Lead → Account
2. Account → RFQ assisted by Sales/Purchasing
3. Won quote → Order linkage on opportunity
4. Post-delivery follow-up tasks

## UI requirements

- Account list with type/stage/owner
- Account detail with related RFQs/orders (Phase 2)
- Activity timeline (Phase 2)

## Permissions

- Sales: own + team accounts
- Purchasing: supplier-side accounts
- Admin: all
