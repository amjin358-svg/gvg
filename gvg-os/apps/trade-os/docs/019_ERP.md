# 019 — ERP

## Positioning

GVG Trade OS is not a full ERP replacement in v1. It provides trade-ops ERP-lite capabilities and integrates outbound to accounting ERP later.

## ERP-lite domains in-platform

| Domain | Coverage in v1/v2 |
|---|---|
| Item master | Products / SKUs |
| Vendors / customers | CRM accounts + profiles |
| Sales orders | Orders module |
| Purchase intents | RFQ / procurement |
| Inventory | WMS balances |
| Basic invoicing | Finance module (Phase 2) |

## Out of scope initially

- Full general ledger
- Fixed assets
- Payroll
- Complex MRP explosions

## Integration strategy (Phase 3)

- Export journals / invoices to QuickBooks, NetSuite, or Xero
- Webhook + scheduled sync
- Idempotent external IDs on orders/invoices
