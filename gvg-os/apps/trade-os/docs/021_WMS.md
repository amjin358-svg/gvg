# 021 — WMS (Warehouse Management)

## Modules

- Inventory (`/inventory`)
- Warehouses (`/warehouses`)

## Warehouse master

| Field | Description |
|---|---|
| code | e.g. `LAX-01` |
| name | Hub name |
| city / country | Location |
| capacity_units | Storage capacity |
| utilization_pct | Current utilization |

## Inventory model (Phase 2 tables)

`inventory_balances(sku, warehouse_id, qty_on_hand, qty_reserved, qty_available)`

## Processes

| Process | Description |
|---|---|
| Receive | Inbound ASN / PO receipt |
| Putaway | Location assignment |
| Reserve | On order confirm |
| Pick / Pack | Outbound wave (Phase 2) |
| Adjust | Cycle count variance |

## Role access

- Warehouse: operate balances & tasks
- Purchasing: visibility for replenishment
- Supplier: limited view of consigned stock (optional)
- Finance: valuation views (Phase 2)

## KPIs

- Utilization
- Inventory accuracy
- Order fill rate
- Dock-to-stock time (Phase 2)
