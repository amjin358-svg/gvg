## 2. Logo system

### Files

| Asset | Path | Use |
|---|---|---|
| Mark | `/brand/gvg-mark.svg` | App icon, avatar, favicon source |
| Company lockup | `/brand/gvg-lockup.svg` | Letterhead, proposals, website header alt |
| Product lockup (light) | `/brand/gvg-product-lockup.svg` | Light backgrounds |
| Product lockup (dark) | `/brand/gvg-product-lockup-dark.svg` | Dark heroes / decks |

### Clear space

Minimum clear space = height of the “G” in the mark on all sides.

### Minimum size

| Asset | Min width |
|---|---|
| Mark | 24px digital / 8mm print |
| Horizontal lockup | 120px digital / 40mm print |

### Do / Don’t

**Do**

- Use mark on ink navy or white  
- Keep teal bar under wordmark intact  
- Prefer SVG; PNG exports at 2× for raster needs  

**Don’t**

- Recolor mark to purple/gradient packs  
- Stretch, rotate, or add drop shadows  
- Place low-contrast mark on busy photography without scrim  
- Recreate letters in Arial/Inter as a “logo”

## 4. Typography

| Role | Font | Notes |
|---|---|---|
| Display / brand | Outfit | Headlines, lockups |
| Body / UI | Source Sans 3 | Long text, UI labels |
| Mono (optional) | System mono | SKUs, codes only |

Avoid Inter / Roboto / Arial as brand display faces.

## 5. Voice & tone

- Clear, commercial, international  
- Prefer verbs of motion: connect, source, ship, scale  
- Avoid hype slang and emoji in formal collateral  
- EN primary; localized variants keep the same hierarchy  

## 6. Imagery

- Real trade context: ports, packaging, QC, warehouse flow  
- Prefer full-bleed atmospheric plates on marketing pages  
- No sticker badges over hero media  
- Abstract gradients alone are not the main visual idea
