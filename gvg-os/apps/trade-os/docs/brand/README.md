## Preview templates locally

With the Next.js app running (`npm run dev`), open:

- http://localhost:3000/brand/gvg-mark.svg
- Or open the HTML templates directly in a browser (logo `src` paths work best via the dev server or by adjusting relative paths).

For print: open template → Print → Save as PDF.
