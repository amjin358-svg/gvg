# Frontend domain

Feature modules and presentation-adjacent data for the Next.js app.

```
frontend/
├── data/mock/     # Demo catalog, RFQs, orders, shipments
└── features/
    ├── ai/        # AI Procurement Assistant
    ├── home/      # Landing sections
    └── products/  # Product repository
```

UI primitives live in `/components`. Routes live in `/app`.
