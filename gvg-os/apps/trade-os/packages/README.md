# Packages

Shared libraries for the GVG monorepo.

| Package | Purpose |
|---|---|
| `packages/config` | Shared ESLint / TS / Tailwind config exports |
| `packages/ui` | Future shared UI kit (extracted from `components/`) |
| `packages/tsconfig` | Base TypeScript configs |

Phase 1 keeps UI in `/components` and shared utils in `/lib`.
