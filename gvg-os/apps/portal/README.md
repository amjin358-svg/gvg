# @gvg/portal — GVG 企業官網（最初版格式）

與 cinematic 行銷站（`@gvg/website` / V4 備份）分離。文案以**繁體中文為主（約 80%）**，英文為輔。

## 頁面

| 路由 | 說明 |
| --- | --- |
| `/` | 首頁：港口 Hero、六大業務項目、熱門產品分類 |
| `/about` | 關於 GVG |
| `/services` | 服務項目 |
| `/products` | **商品中心**總覽 |
| `/products/[category]` | 品類列表（五金、居家、保健、食品、建材、辦公） |
| `/trade` | 貿易中心 |
| `/suppliers` | 供應商合作 |
| `/news` | 最新消息 |
| `/contact` | 聯絡／詢價 |

## 開發

```bash
# from gvg-os/
npm run dev:portal
```

http://localhost:3001
